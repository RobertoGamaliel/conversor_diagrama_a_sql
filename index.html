¿Para qué sirve y cómo usarlo?
¿Para qué sirve el generador de tablas?

Este generador te permite crear, en cuestión de segundos, una tabla SQL a partir de un diagrama.

En lo personal, utilizo la página app.diagrams.net para hacer mis diagramas porque es gratuita. Sin embargo, convertir esos diagramas a sentencias SQL puede llevar tiempo. Por eso desarrollé esta herramienta para uso personal, pero si tú también usas esta plataforma, puede serte de gran ayuda. Solo necesitas diseñar tu diagrama y este generador te devolverá la sentencia SQL correspondiente para crear tu tabla.

¿Cómo se usa?

Debes utilizar la forma llamada List, ubicada en el apartado Avanzado de la barra lateral izquierda. En la siguiente imagen se muestra un ejemplo:

Llena la forma siguiendo estas instrucciones:

  • El primer elemento debe ser el nombre de la tabla (sin espacios). En la sintaxis de ejemplo, es donde dice nombre_de_la_tabla.
  • Puedes agregar tantas columnas como necesites. Cada una debe tener una estructura específica para que el conversor pueda interpretarla correctamente:
  • nombre_de_columna: obligatorio. Solo texto, igual que en SQL estándar.
  • tipo_dato: obligatorio. Puede incluir tipo y restricciones, como int unsigned not null, float, varchar(20), etc.
  • configuración_adicional: opcional. Existen tres posibles casos:
    — pk: si es llave primaria (PRIMARY KEY).
    — index: si deseas indexar ese campo.
    — tabla_referenciada,columna_referenciada: si es llave foránea (FOREIGN KEY), se indica con el nombre de la tabla y la columna de referencia.
  • Los parámetros deben ir separados por : para que el generador los interprete correctamente.

En la siguiente imagen se muestra un ejemplo completo, con la sintaxis y los tres casos de configuración:

Una vez que tengas lista tu forma con los datos de la tabla, selecciónala, haz clic derecho y elige la opción Copiar (no copiar como imagen). También puedes usar Ctrl + C, aunque a veces puede copiarse como imagen hexadecimal, lo que impide que el conversor la lea correctamente.

No necesitas presionar ningún botón. Simplemente pega el contenido en el campo del conversor. Si el texto es válido, se generará automáticamente la sentencia SQL. Si hay errores, se mostrará un mensaje para que ingreses un texto correcto.

Si trabajas con Laravel y generas tus tablas con artisan migrate, puedes hacer clic en el botón Artisan y obtendrás la migración lista para crear la tabla con el comando:
php artisan migrate

Cuando copias una forma del diagrama, se genera un XML. El XML correspondiente al ejemplo anterior se convertiría en la siguiente sentencia SQL: 

CREATE TABLE IF NOT EXISTS libros (
  id BIGINT UNSIGNED NOT NULL PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(255) NOT NULL,
  fecha_carga DATETIME NOT NULL,
  autor INT UNSIGNED NOT NULL,
  FOREIGN KEY (autor) REFERENCES autores(id),
  INDEX libros_idx0 (fecha_carga)
);
